# Chapter 01: Introduction to Python for Developers

Coursework, notes, and exercises for the first course in the DataCamp Associate Python Developer track.

## Topics Covered
- Python fundamentals, variables, and primitive data types (integers, floats, strings, booleans)
- Type casting and arithmetic/logical operations
- String formatting (f-strings) and built-in string methods
- Basic data structures (lists, indexing, slicing)
- Functions and script execution

## Contents
- `notes.md` — Synthesized conceptual notes and syntax reference.
- `exercises/` — Practice scripts and code snippets.
