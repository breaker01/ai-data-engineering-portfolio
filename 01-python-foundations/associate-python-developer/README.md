## Directory Conventions

Inside each chapter directory:
- `notes.md`: Key concepts, syntax snippets, pitfalls, and theoretical explanations.
- `exercises/` or `*.py`: Practice scripts, code snippets, and exercise solutions.
- For projects: Modular script files, inputs/sample data, and a standalone `README.md` documenting requirements, approach, and how to run tests/scripts.
